# Передача владельцу и верстальщику

Это версия для согласования текста и структуры главной страницы. Она не опубликована в WordPress.

Для владельца:
- согласовать смысл новых формулировок;
- подтвердить скидку -10% на первый заказ;
- подтвердить возможность предварительного расчета по фото;
- подтвердить выезд по Хмельницкой области;
- подтвердить быстрые переходы на услуги.

Для верстальщика:
- переносить только подсвеченные фрагменты и новые блоки;
- не менять визуальный стиль Elementor;
- не менять существующие фото, CTA, формы и блоки отзывов;
- FAQ сделать видимым на странице;
- schema добавлять после видимого FAQ.
