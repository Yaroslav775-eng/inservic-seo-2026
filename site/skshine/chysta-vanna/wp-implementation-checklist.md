# Checklist для впровадження у WordPress

- URL не змінювати: https://skshine.com.ua/chusta-vanna/
- Дизайн, фото, ціни, форми, CTA, header і footer не змінювати.
- Оновити Title, Description і H1 з SEO-паспорта.
- Перенести тільки підсвічені фрагменти та нові текстові блоки з прототипу.
- Зберегти ціни на картках: STANDART від 1200 грн, PREMIUM від 2400 грн.
- Додати блок “Коротко: що приводимо до ладу у ванній”.
- Додати блок “STANDART чи PREMIUM: як вибрати”.
- Додати блок “Що впливає на час і вартість”.
- Додати видимий FAQ перед schema.
- Додати Service + FAQPage schema тільки після того, як FAQ є видимим на сторінці.
- Перевірити після верстки: один H1, коректне відображення на мобільному, не зникли кнопки зв’язку.
- Не відправляти на переобхід у Google Search Console без окремого підтвердження.
