# Передача владельцу и верстальщику

Это версия для согласования текста и структуры. Она не опубликована в WordPress.

Для владельца подтвердить:
- работу с ОСББ и управляющими компаниями;
- регулярные графики прибирання территории;
- актуальность цен по бруківці, фасаду и огорожі;
- оплату на расчетный счет;
- расчет по фото;
- выезд по Хмельницкой области.

Для верстальщика:
- переносить только подсвеченные фрагменты и новые блоки;
- визуальный стиль Elementor не менять;
- существующие цены, карточки, форму и CTA оставить;
- FAQ сделать видимым;
- schema добавить только после видимого FAQ.
