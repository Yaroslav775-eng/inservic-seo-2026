# Checklist впровадження: бізнес-послуги

URL: https://skshine.com.ua/biznes-poslugu/
Статус: Approval Ready.

## Не змінювати

- URL.
- Поточний Elementor-дизайн.
- Фото без окремого погодження.
- Форми і CTA.
- Шапку, футер, кольори, сітку.

## Перенести

- H1 і перший екран.
- Блоки сегментів бізнесу.
- `Що можна замовити для бізнесу`.
- Фактори ціни.
- Організацію регулярного клінінгу.
- `Що входить у базове прибирання офісу`.
- Блок довіри для B2B.
- FAQ з 10 питань.
- Нижній SEO-текст.

## Після верстки

- Перевірити один H1.
- Перевірити, що FAQ видимий.
- Перевірити, що форма працює.
- Перевірити мобільну версію.
- Додати schema після погодження.
- Після підтвердження відправити URL у GSC.
