Задача

Не створювати нову URL і не ламати чинний дизайн. Посилити наявну сторінку змістом і блоками з прототипу.

Чинна URL: відкрити сторінку
Прототип: відкрити локально

Що змінити

  1. Зберегти чинну URL, шапку, футер і загальний стиль WordPress.
  2. Замінити шаблонний description без твердження «підтримка 24/7».
  3. Додати блоки симптомів, діагностики, безпечної самоперевірки, ТО, процесу та FAQ.
  4. Залишити чинні ціни без самостійної зміни.
  5. Додати розмітку BreadcrumbList, Service і FAQPage; FAQ у schema має дослівно відповідати видимому FAQ.
  6. Підключити чинну форму Contact Form 7 та відстеження дзвінка/відправлення.
  7. Додати внутрішні посилання на бензинові, дизельні генератори та сторінку ремонту генераторів.

Не вигадувати

  • Не обіцяти фіксований строк ремонту до діагностики.
  • Не додавати бренди без підтвердження майстерні.
  • Не змінювати ціни та умови гарантії без погодження.
  • Не писати про виїзд майстра.
  • Не оптимізувати сторінку під Київ або інші міста.

Потрібно погодити

Список брендів, точні умови гарантії 1-12 місяців, можливість ремонту конкретних потужностей, реальні фото й кейси.

Контроль після верстки

Один H1; canonical без змін; форма працює; телефони клікабельні; ціни збігаються з чинною сторінкою; schema валідна; мобільна версія без горизонтального скролу; сторінка не закрита від індексації.
